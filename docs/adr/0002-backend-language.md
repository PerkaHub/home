# 0002. Использовать Python 3.12 и FastAPI 0.115.6

- **Статус**: предложено
- **Дата**: 2026-11-07
- **Участники**: Белянский Глеб, Опекин Егор, Рогачев Егор; согласование запланировано

## Контекст

Нужен HTTP backend для FR-01–FR-06 в рамках учебного стека.

## Движущие факторы

C-04 предписывает Python + FastAPI по методичке; NFR-01 требует измеримой задержки; NFR-04 не различает варианты — права проверяются в любом стеке. Источники: [требования](../requirements.md), [агрегаты](../domain/aggregates.md).

## Рассмотренные варианты

| Вариант | За | Против |
|---|---|---|
| Python 3.12 + FastAPI 0.115.6 | Быстрые типизированные HTTP-контракты; соответствует курсу | Нужны отдельные миграции и дисциплина слоёв |
| Python + Django | Готовая админка и ORM | Больше встроенных соглашений для небольшого API |

## Решение

Python 3.12, FastAPI 0.115.6, SQLAlchemy 2.0.36, Alembic 1.14.0; PostgreSQL 17.2; worker использует тот же код Python. Web — статические HTML/CSS/JS в nginx 1.27.3. Версии зафиксированы для воспроизводимого окружения.

Определяющий довод — ограничение C-04: Python и FastAPI входят в учебный стек. Для выбора Django потребуется согласование исключения.

## Последствия

Положительные: Быстрые типизированные HTTP-контракты; соответствует курсу. Отрицательные: Дополнительное сопровождение ORM/миграций и worker. Что пересмотрит решение: Изменение кафедрального стека или невозможность достичь NFR-01.
