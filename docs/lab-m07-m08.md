# Лабораторная работа № 3. Сервис и проектирование кода

Проект «ДомПрозрачно», модули М07 и М08. Команда — Белянский Глеб, Опекин Егор и Рогачев Егор.

## 3А. Первый сервис

Сервис написан на Python 3.12 и FastAPI 0.115.6 по ADR‑0002. Точка входа — `python -m domprozrachno`. Фабрика приложения получает проверенные настройки. Без `DATABASE_URL` сервис завершает запуск с кодом 2, ошибку пишет в stdout без значения переменной. `/health` показывает живость процесса, `/version` — версию и среду запуска. Журнал — JSON с UTC-временем, уровнем, именем события и ID запроса.

Compose поднимает `api` и `db`. Они совпадают с контейнерами на [диаграмме C4](architecture/c4/container.mmd). Образ устанавливает зависимости из `uv.lock` без dev-группы и запускает API от пользователя `app`. Порт PostgreSQL доступен только внутри сети Compose, данные находятся в именованном томе.

## 3Б. Публикация начисления

Реализовали публикацию начисления по FR‑02. API создаёт черновик, публикует его и возвращает опубликованное начисление по ID. Агрегат проверяет месяц и сумму строк в копейках. Хранилище разрешает одну публикацию на счёт и месяц, в том числе при одновременных запросах. Подробный разбор швов, паттернов и сравнение до и после — в [отчёте о рефакторинге](refactoring-notes.md).

Исходную HTTP-версию и 14 тестов зафиксировали в [первом коммите сценария](https://github.com/PerkaHub/home/commit/e758b41fc01eff63488ccd764d60785622c0e8dd). Затем [выделили домен и сценарий публикации](https://github.com/PerkaHub/home/commit/81078ccfd971ef4c87622f6a04ae8b3b2e0f62b2). Имена реализованных классов сверяются с [глоссарием](domain/ubiquitous-language.md). Связи кода с требованиями и проверками приведены в [матрице](traceability.md).

## Как показать работу

Запуск и готовое тело запроса есть в [README](../README.md). На защите достаточно показать `/health`, `/version`, провести публикацию через Swagger UI, повторить тот же запрос для 409 и сопоставить события с одинаковым `X-Request-Id`. Точный момент публикации и исходящее событие проверяются отдельно тестом сервиса без HTTP.
