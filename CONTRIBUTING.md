# Внесение изменений

GitHub Flow: одна короткая ветка на связную задачу, один запрос и ревью другим участником. Для трёх человек и общей поставки постоянные release/develop-ветки не нужны. До отправки выполнить проверки из README. Формат коммита: docs(scope): описание или ci(scope): описание.

В описании изменения назвать требования, затронутые решения и цену выбора, перечислить проверенные диаграммы и результат локальных проверок. Ревью: сначала согласованность требований и правил, затем безопасность платежа, затем оформление. Для принятия ADR нужно реальное подтверждение командой; статус не повышается автоматически.

Настройка branch protection и права доступа на GitHub проверяются отдельно от локальных проверок документов.
