Модель переходов проверяет сохранение итогового состояния и единственность финансового эффекта при заданном идемпотентном контракте провайдера. Она служит проверкой проектного протокола; миграции, прикладной код и интеграционные испытания относятся к следующим лабораторным.

Среда проверки: Python 3.11, Node.js 25.2.1, Mermaid CLI 11.4.2. Версии npm-зависимостей закреплены в package-lock.json. Результаты отрисовки находятся в build/diagrams и исключены из Git.

## Принятые решения и следующие этапы

- Уточнить с представителем УК право выдачи приглашений и достаточность категорий расходов; вопросы включены в сценарный разбор.
- ADR-0001–0005 приняты для текущей спецификации по поручению владельца проекта; замечания последующих ревью учитываются отдельными изменениями.
- Подтвердить контракт выбранного sandbox: merchant id, проверку подлинности, идемпотентный create и срок хранения ключа.
- Перед испытаниями уточнить исходные BR-оценки по измерениям; после реализации проверить NFR-01–NFR-06.

Доступ к GitHub и параметры защиты main проверяются отдельно. Локальные проверки выполнены перед публикацией ветки lab2.
